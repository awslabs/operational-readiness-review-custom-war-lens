# Lens files

This folder keeps the lens files that earlier links point to, including the 2023 announcement blog post and earlier
versions of the README.

## v1 files (kept unchanged)

| File | Version |
|---|---|
| `orr-v1.3.2-PUBLISHED.json` | 1.3.2 (2023-03-06) |
| `orr-v1.3.3-PUBLISHED.json` | 1.3.3 (2023-04-27) |
| `orr-v1.3.4-PUBLISHED.json` | 1.3.4 (2023-05-19) |
| `orr-v1.3.5-PUBLISHED.json` | 1.3.5 (2023-07-10) |
| `orr-v1.3.6-PUBLISHED.json` | 1.3.6 (2023-09-13) |

These files are never moved, renamed, edited or deleted, so existing links keep working. They are kept for
reference only: v1.3.x has known scoring limitations (see the
[README](../README.md#known-scoring-limitations-of-v13x)). For a new install, use the current release. To move a
lens you already imported from v1.3.x to 2.0.0, follow [`MIGRATION.md`](../MIGRATION.md): edit your existing lens,
never create a second one.

## Released files (from 2.0.0)

Each release's lens files are copied here unchanged, in pretty and minified form, for example:

- `orr-core-2.0.0.json` and `orr-core-2.0.0.min.json` (Operational Readiness Review (ORR) core lens)
- `orr-event-1.0.0.json` and `orr-event-1.0.0.min.json` (ORR - Mission-Critical Event Readiness)

The copies are generated by the release build and must match the release assets. Do not edit them by hand.

## Where to download

The primary source is [GitHub Releases](https://github.com/awslabs/operational-readiness-review-custom-war-lens/releases).
Each release attaches every lens file, a `manifest.json` and a `SHA256SUMS` file; release tags and checksums
replace the `-PUBLISHED` suffix used for the v1 files.

Stable links that always return the newest release:

- https://github.com/awslabs/operational-readiness-review-custom-war-lens/releases/latest/download/orr-core.json
- https://github.com/awslabs/operational-readiness-review-custom-war-lens/releases/latest/download/orr-core.min.json
- https://github.com/awslabs/operational-readiness-review-custom-war-lens/releases/latest/download/orr-event.json
- https://github.com/awslabs/operational-readiness-review-custom-war-lens/releases/latest/download/orr-event.min.json

Install and upgrade steps are in the [README](../README.md#quick-start).
