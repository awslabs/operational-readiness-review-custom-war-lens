### `gai_agent_bounds`: Agent actions pass one enforced control point and can be stopped fast

Maximum risk: High. Category: Blast radius containment. Core path: no.

Question: If an agent misbehaves, are its actions blocked by controls it cannot bypass, and can an operator stop it and its running sessions within minutes?

Out of scope if: no agent or model output can call a tool or trigger an action with side effects. Select the first statement and keep the tool list and permissions as evidence.

Evidence to collect: the tool list with read or write classification. The enforcement point, its mode, the backend resource policies and who can change them. The stop procedure and the record of its last exercise with time to stop. The runaway-loop test result.

Statements:

- `ab_single_enforcement` (core): No agent can reach a tool backend except through the enforcing authorization point, and changes to its mode or attachment alarm
- `ab_stop_exercised` (secondary): An operator-initiated stop of all agent actions, which also ends in-flight sessions, was exercised and its time to stop recorded

3. High: otherwise
